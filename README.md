# Ultra Girl

**Ultra Girl** is a retro-inspired action platformer created as an AI-assisted game development experiment.

Run, jump, shoot, and survive through an increasingly challenging adventure featuring procedurally generated levels, multiple world themes, original chiptune-style music, collectible powerups, and relentless enemy waves.

What begins as a simple platforming challenge gradually evolves into a demanding test of reflexes and perseverance.

## Features

- Fast-paced action platforming
- Procedurally generated level layouts
- Multiple themed environments
- Increasing difficulty progression
- Original retro-inspired soundtrack generated with Web Audio
- Flying and ground-based enemies
- Health system and collectible heart pickups
- High score tracking
- Keyboard and touch controls
- Mobile-friendly browser support
- Single-file HTML game with no external dependencies

## Controls

### Keyboard

| Action | Keys |
|----------|----------|
| Move Left | A / Left Arrow |
| Move Right | D / Right Arrow |
| Jump | W / Up Arrow / Space |
| Shoot | J / Z / X / Shift |
| Mute Audio | M |

### Mobile

Touch controls are automatically enabled on supported devices.

## Technical Details

Ultra Girl is built entirely with:

- HTML5
- JavaScript
- Canvas API
- Web Audio API

No frameworks, engines, or external libraries are required.

## About The Project

This project was created as an experiment in AI-assisted game development.

Gameplay systems, balancing, enemy behavior, graphics, level generation, music synthesis, and user interface elements were developed through an iterative collaboration between a human developer and AI tools.

The goal was to explore how far a complete browser game could be developed using modern AI-assisted workflows while keeping the final game lightweight, portable, and easy to distribute.
